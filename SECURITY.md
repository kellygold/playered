# Security

Please report vulnerabilities privately through this repository's GitHub Security
Advisories reporting feature, if enabled, rather than opening a public issue with
exploitation details or personal data. If private reporting is unavailable, ask
for a private contact without posting the sensitive details.

Include the version, operating system, reproduction steps using synthetic data,
and redacted diagnostics. Never include API keys, private images, workspace backups,
or identifiable user data. The latest beta is the supported reporting target;
this volunteer project does not promise response or fix timelines.

The service is intended for one user's computer, bound to loopback. Running it as
an internet-facing or shared network service is not a supported configuration.
